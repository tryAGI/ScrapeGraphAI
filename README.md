## Features 🔥
- Fully generated C# SDK based on [official ScrapeGraphAI OpenAPI specification](https://api.scrapegraphai.com/openapi.json) using [AutoSDK](https://github.com/HavenDV/AutoSDK)
- Same day update to support new features
- Updated and supported automatically if there are no breaking changes
- All modern .NET features - nullability, trimming, NativeAOT, etc.
- Support .Net Framework/.Net Standard 2.0

### Usage
```csharp
using ScrapeGraphAI;

using var client = new ScrapeGraphAIClient(apiKey);
```
